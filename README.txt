MOTORWORKS TYCOON - installable web app

Put every file in this folder on any HTTPS web host, then open the address.
Quick free options: Netlify Drop (app.netlify.com/drop - drag this folder in),
GitHub Pages, Cloudflare Pages or Vercel.

Install
- iPhone / iPad: open the link in Safari > Share > Add to Home Screen.
- Mac: Safari > File > Add to Dock (macOS Sonoma or later),
  or Chrome / Edge > the install icon in the address bar.
- Android: open the link in Chrome > menu (three dots) > Install app
  (or Add to Home screen). Samsung Internet: menu > Add page to > Home screen.
- Windows: Chrome or Edge > Install app.

Once opened, the game works offline. Each device keeps its own save.
To move a company between devices: Menu > Copy save code, send it to
yourself, then paste it on the other device's start screen.
Test locally: run  python3 -m http.server  in this folder and open
http://localhost:8000 (service workers need https or localhost).
